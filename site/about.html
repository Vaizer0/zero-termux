About Zero-Termux

Zero-Termux is a modular development environment and signed APT package repository for Termux: one zero CLI covering 99 tools across 9 modules, plus 228 packages available through apt — installed, signed, and documented from a single GitHub repository.

Design goals

  • Uniformity: every tool has the same four verbs — install, update, reinstall, uninstall.
  • Currency: rolling versions; the latest release of each tool at install time, with pins only where builds demand them.
  • Transparency: the entire ecosystem — installers, package scripts, CI, docs — is plain text in one repository.
  • Termux-native: no root, no systemd, no sudo. Everything under $HOME and $PREFIX.
