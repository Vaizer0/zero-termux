# Features

Two ecosystems, one command. The zero CLI manages module installs; the APT repository provides Debian packages — both rolling to latest versions.

◈Modular CLI

zero install lang · db · ai · editor · dev · npm · shell · ui · auto — category-based installers with install/update/reinstall/uninstall lifecycle.

▣228 APT packages

Security, recon, net, web, and dev tools as signed Debian packages — installed and upgraded with plain pkg.

↻Rolling versions

Registry tools track @latest; GitHub-release binaries resolve the newest release at install time. No stale pins.

🔑Signed repository

Every release is GPG-signed. The public key ships as assets/zero-termux.gpg; the private key never leaves CI secrets.

⚡One-line install

The installer sets up dependencies, clones the repo, links zero, and configures the APT source — with one-time migration from legacy installs.

☰Transparent

Every package installs from source on-device with visible DEBIAN/ scripts, and a CI test suite guards branding, pins, and stale URLs.

# Modules

Install whole categories with one command. Each module installs individual tools with their own lifecycle:

langzero install lang dbzero install db aizero install ai editorzero install editor devzero install dev npmzero install npm shellzero install shell uizero install ui autozero install auto

λlang

Programming language toolchains and runtimes — Go, Rust, Node, Python, and more, pinned to Termux-compatible versions.

▤db

Databases and data stores: PostgreSQL, MariaDB, Redis, MongoDB, SQLite — installed, configured, and managed locally.

✧ai

AI coding agents and CLI assistants: qwen-code, opencode, claude-code, gemini-cli, ollama, and more — always the latest release.

▚editor

Terminal editors and editor frameworks — Neovim-based setups including nvchad and lazyvim.

⚙dev

Developer utilities: bat, curl, cloudflared, and the everyday tooling that makes Termux a real workstation.

⬢npm

Node.js CLI tools installed globally with @latest — turbopack, 9router, and friends.

❯shell

Shell upgrades: ZSH with plugins and a polished prompt, ready to use.

▦ui

Termux UI tooling — widgets, themes, and desktop helpers for a richer Termux experience.

⟳auto

Automation: n8n workflow automation running on-device for local and cloud workflows.

# APT Repository

The Zero-Termux repository is signed and served from GitHub Pages. Add it with the installer, or manually:

# /data/data/com.termux/files/usr/etc/apt/sources.list.d/zero-termux.list
deb [trusted=yes arch=all] https://vaizer0.github.io/zero-termux/repo zero-termux main

$ curl -fsSL https://vaizer0.github.io/zero-termux/zero-termux.gpg -o $PREFIX/etc/apt/trusted.gpg.d/zero-termux.gpg
$ apt update

# search, install, upgrade — like any other repository
$ pkg search zaproxy
$ pkg install zaproxy

Browse the full catalog in assets/PACKAGES.md.
