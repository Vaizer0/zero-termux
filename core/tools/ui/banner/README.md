# Banner Configuration for Termux

Customize Termux with Zero-Termux Banner

**Package:** zero-termux (banner config)  
**Author:** DevCoreX  
**Repository:** https://github.com/Vaizer0/zero-termux  
**Type:** Termux UI customization  
**License:** MIT

## Description

Configure a custom banner for Termux using Zero-Termux. This package allows you to set a personalized welcome message that appears when you start Termux, enhancing your terminal experience.

## Dependencies

- Termux (base installation)

## Install

```bash
core install ui --banner
```

## Uninstall

```bash
core uninstall ui --banner
```

## Update

```bash
core update ui --banner
```

## Notes

- Source file: `~/.local/share/zero-termux/assets/banner/zero-termux.txt`
- removes Termux welcome message: motd
- Restart Termux to apply changes
